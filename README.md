# ChatGPT-UI-Clone
A web application that simulates the ChatGPT interface with streaming text and responsive layout.
## ✨ Key Features
Real-Time UI & Voice Experience: Accurately replicates the ChatGPT interface for both text and voice chat.

Feature-Complete UI: Virtually all interactive elements and layouts are fully cloned (note: responses appear instantly rather than streaming token-by-token).

Markdown & Code Highlighting:** Supports formatted responses and copyable code blocks.

Responsive Layout:Includes a collapsible sidebar for chat history.

Dark/Light mode toggle
